Overview

InvokeDB enables developers to build data driven user interfaces without the overhead of a complex database or a back end API.

Once a table is created, endpoints become available and can be integrated into an application.

At its core InvokeDB provides 2 main features:

  1. A Data Table UI - for administration
  2. An API - for external app integration

Think of a data table as a spreadsheet but with the ability to set column types to allow for more advanced filtering and sorting. A data table can be built from scratch or generated from a CSV file.

Each data table has its own API endpoints that allow an external app to create, delete and edit fields.

Creating a new table

Empty Table - To create a new empty table, go to the Tables page and click the + icon. Then click the Data Table menu item. A new table will be created with 3 rows and 3 columns. To edit the table, see the Data Table UI Section below.

Upload CSV - To convert a CSV File into an InvokeDB data table, go to the Tables page and click the + icon. Then click the Upload CSV menu item. Within the upload dialog you will then need to choose a CSV File from your file system and click upload.

Pricing Tiers

Depending on your current plan you will be limited to the amount rows, tables and requests per minute your api is allowed to make. See the pricing page for the available tiers.

Data Table UI

The Data Table UI provides many of the same features a standard spreadsheet does. Let's go over the top bar first. From left to right here is what is displayed:

  1. Table ID - This will be helpful when integrating api endpoints into an application
  2. Cancel (X icon) - This will toggle out of row or column edit mode
  3. Delete (trash icon) - Removes rows that are highlighted
  4. Save (disk icon) - Submits pending changes to rows or columns
  5. Edit Columns - Toggles table into edit mode
  6. Add Column - Add a column. (Only appears when in edit column mode)
  7. Add Row - Add a row.
  8. Refresh - Refresh table. This can be helpful when changes were made by an external app using the api.
  9. Total rows - Total rows in the table (taking into account any filters applied).
  10. API - Shows the tables available URL Endpoints.

The Row Column

The first column in every table is the 'Row' column. Think of this column as just the row number of the returned results. It does not represent an ID of a row. It is sortable and filterable and can be used in combination with the other columns which can be helpful when trying to find a particular row.

Edit Row

To edit fields within a row, single or double click on the field and begin typing. When tabbing or clicking off the field, the data is automatically saved to the server.

Delete Rows

Click to select a row. To select multiple rows, shift + click or ctrl + click a second row. When at least one row is selected click the trash icon in the top bar.

Add Rows

Click the Add Row button in the top bar. You will only be able to edit 'Added Rows' when in this mode. Click the disk icon to save the new rows to the server. Click the X icon to cancel.

Add Column

Click the Edit Columns button in the top bar. When in edit mode, click the Add Column button. Add a name to the column. Click the disk icon to save or the X icon to cancel.

Remove Column

Click the Edit Columns button in the top bar. When in edit mode, click the minus icon inside the column header to remove the column. Click the disk icon to save or the X icon to cancel.

Rename Column

Click the Edit Columns button in the top bar. When in edit mode, change the name of the column. Click the disk icon to save or the X icon to cancel.

Change Column Type

Click the Edit Columns button in the top bar. When in edit mode, click the first square button inside the column. This will open up a menu displaying the available column types. Select the new column type. Click the disk icon to save or the X icon to cancel.

Depending on the amount of data in the table this could take several minutes. Also be aware that if a field can not be converted into the new column type (ex. 'abc' to a number) the field will become NULL and cannot be reverted.

Index Column

Column indexing is necessary when wanting to filter on a particular column and the table has a large number of rows. To index a column click the Edit Columns button in the top bar. When in edit mode, click the i button inside the column header. This will change the button to a solid blue color. Click the disk icon to save or the X icon to cancel.

Filtering

Each column has an input box below the column name which can be used to filter data returned to the table. There is also a button on the left side of each input which allows you to change the filter type. The following types are available.

For String Columns:

≈ Contains. Case insensitive.

= Equals. Must match exactly.

For Date and Number Columns:

= Equals. Must match exactly.

< Less than.

<= Less than or Equal to.

> Greater than.

>= Greater than or Equal to.

Sorting

To filter a column in ascending order, click the column header once. To filter a column in descending order click the column header a second time. To remove sorting, click the column header a third time. Only 1 column can be sorted at a time.

App Integration

To integrate InvokeDB's API into your application you must first obtain your account's api_key from the account page.

The api_key will be used as a query parameter in the API URL endpoints. For documentation on how to use the api, visit the api docs.
