Agent quickstart

Give your AI agent a database

Connect Claude, Cursor or any MCP client to InvokeDB and it can read, query and change your tables, while you see every row in a spreadsheet. It takes a couple of minutes.

What an agent can do

  • See your tables: list them, with their columns and row counts.
  • Query and count rows: filters, sorting and paging, and the saved views you made in the app.
  • Add, update and delete rows, up to 100 a call, with a read-and-write key.
  • Make tables and add columns (text, number or date) with a read-and-write key for all tables.

It does this through InvokeDB's MCP server. Agents that prefer plain HTTP can use the REST API with the same key. The key decides what an agent may touch, every change is in the table's history under the key's name, and each tool call counts as one API call on your plan.

    Make a free account with an email, Google or GitHub. With an email, confirm it with the link we send you before you make tables or keys.

  2. 2 Make a table

    On the Tables page, click +. A Table from Template (a CRM, a task list, an inventory…) comes with sample rows, so the agent has something to work with at once. You can also upload a CSV, import a URL or Google Sheet, or describe the table and let AI suggest it.

  3. 3 Make an API key

    On the Account page, under API Keys, click New key. Choose Read and write if the agent should change rows, and limit it to some tables if you like. Copy it: it's shown only once. Give each agent its own key, so you can see what it did and revoke it on its own.
