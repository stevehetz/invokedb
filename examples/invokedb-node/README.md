# InvokeDB JavaScript Client

> Moved here from `stevehetz/invokedb-node` on 2026-11-15. Published to npm as `invokedb`.
> The default `baseUrl` is `https://api.invokedb.com/v1`; for local dev pass
> `baseUrl: 'http://127.0.0.1:8001/api/v1'`. Build with `npm install && npm run build`.
> `release.sh` dates from the old repo (it commits, pushes `master` and publishes), so don't
> use it here as-is.

## Setup

```
npm install --save invokedb
```
